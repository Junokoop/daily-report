工地照片施工位置分類

AI 辨識照片中拍照立牌／白板上的施工位置文字，依名稱相同自動分組

01

上傳照片，自動辨識分類

每張照片建議包含清楚拍到的拍照立牌或白板，上面寫有施工位置文字。拖曳或選取後會立即開始辨識，也可以之後再陸續加照片，會自動歸到對應位置。分好的位置預設只顯示名稱與張數，點「展開照片」才會列出該組縮圖

辨識設定（部署到 GitHub Pages 必填）

把你的 Google Apps Script Web App 網址貼在這裡，辨識才會透過你自己的金鑰運作。留空時只有在 Claude.ai 對話視窗的預覽環境才能辨識，部署到 GitHub Pages 後會全部辨識失敗。

拖曳照片到這裡 點擊選取檔案（可多選，可分次加入）

02

儲存結果

點選分類名稱可重新命名（與其他組別同名會自動合併，可用來修正辨識誤差）；未辨識到位置的照片可手動輸入或按重試
